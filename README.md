# Mahaganapati: the ocean becomes the deity

![Mahaganapati formed from a monochrome particle ocean](docs/poster.png)

[Watch or download the finished film](https://github.com/nikitph/mahaganapati-particle-ocean/releases/download/v1.0.0/mahaganapati-wave.mp4) · [Formation sequence](docs/progression.png)

Two fframes 1.2.0 passes, 1920 × 1080, 30 fps, 12 seconds, with original synthesized stereo sound.

The first pass projects particles in 3D through a moving camera. It packs color and depth into one 1920 × 2160 atlas video. The second pass uses an SkSL lens shader to read both planes and apply changing focus, depth of field, highlight diffusion, atmospheric grading, vignette and fine grain.

The figure uses 110,000 destinations sampled from the supplied painting. Its depth is a shallow procedural relief, not a reconstructed 3D sculpture. 135,000 additional particles form the ocean; currents, depth, directional wave shading and distance haze continue after convergence. The figure and ocean share a single moving swell deformation. A broad crest rises from the sea; its material coordinates contract into the reference relief between four and eight seconds. The surrounding wave shoulders subside into the ocean at the feet. All particles and the final grade are monochrome. Short exposure samples add trajectory streaks. This is procedural choreography, not a fluid dynamics simulation.

The sound is generated by `score.py`: filtered noise, harmonic drones and a soft arrival chime. The final fframes pass includes that audio.

## Run

Requires macOS Apple silicon, Rust, FFmpeg, x264 ABI 165, and Python with numpy and scipy.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
bash render.sh
```

The committed `src/target.bin` is sufficient to render; `reference.png` documents its source. `make_target.py` can regenerate it with Pillow, numpy and scipy installed. On this Mac the build used `DEVELOPER_DIR=/Library/Developer/CommandLineTools` and `RUSTFLAGS='-L native=/path/to/local/x264/lib'` to use the installed Command Line Tools and a local x264 ABI 165 build. Those overrides are environment-specific and are not hardcoded in the project.

## Project layout

- `src/bin/field.rs`: deterministic ocean, shared wave deformation, particle convergence, color/depth atlas.
- `src/bin/lens.rs` and `src/lens.sksl`: fframes compositing, focus, aperture blur and cinematic finishing.
- `src/lib.rs`: moving camera, projection and timing helpers.
- `src/target.bin`: sampled reference destinations; no bitmap overlay is used in the film.
- `make_target.py`: optional reference resampling.
- `score.py`: original synthesized stereo soundtrack.
- `render.sh`: complete two-pass render pipeline.

Generated frames, intermediary atlas videos, build products and local toolchain installations are ignored. The completed MP4 is distributed through GitHub Releases.
